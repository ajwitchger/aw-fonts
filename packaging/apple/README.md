# Apple configuration-profile adapter

Apple artifacts are generated by `scripts/build.py`; generated `.mobileconfig` files are not committed.

For each selected font, the builder emits one `com.apple.font` child payload inside a single outer `Configuration` profile. Payload identifiers and UUIDs are deterministic for the logical profile/font identity.

The build performs a post-generation allowlist check and fails unless the only payload types are:

- `Configuration`
- `com.apple.font`

The profile contains no MDM, VPN, proxy, Wi-Fi, certificate, web-filter, or other configuration payload.
